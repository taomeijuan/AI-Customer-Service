# Ch03 实施计划：知识库与向量语义检索

> **For implementer:** Use TDD throughout. Write failing test first. Watch it fail. Then implement.

**Goal:** query_faq 内核从 LIKE 查表替换为 BGE-M3+Milvus 语义检索；离线建库（文档切分+对话挖知识）双写幂等可重跑。

**Architecture:** knowledge/（splitter 纯函数 → embedder → milvus_store → ingest 双写编排）+ jobs/mine_qa（暂存→两级去重→入库）+ tools/faq（契约不变换内核）。MySQL 权威源 + Milvus 主键对齐（chunk.id）。

**Tech Stack:** pymilvus MilvusClient · Ollama /v1/embeddings（bge-m3，1024 维）· SQLAlchemy async · docker-compose（milvus+etcd+minio）· colima 6GB

**Context7 核对结论（2026-10-05）：**
1. `MilvusClient(uri)`；建集合 schema 路径：`client.create_schema(auto_id=False)` + `add_field("id", DataType.INT64, is_primary=True)` + `add_field("vector", DataType.FLOAT_VECTOR, dim=1024)` + VARCHAR 字段需 `max_length`；`IndexParams().add_index("vector", index_type="AUTOINDEX", metric_type="COSINE")`
2. `client.insert(collection, data=[{...}])` → `{"insert_count", "ids"}`；同主键重复 insert 不报错但语义为追加——**幂等用 upsert**：`client.upsert(collection, data)`（同 id 覆盖）
3. `client.search(collection, data=[query_vec], limit=k, output_fields=[...])` → `res[0]` 列表，命中含 `id/distance/entity`
4. Ollama `POST /v1/embeddings` `{model, input: str|[str]}` → `{data: [{embedding, index}]}`，数组输入即批量；bge-m3 1024 维

**约定：** 单测 Fake embedder/milvus（快、可断言状态机）；集成/验收真连本地服务；每任务绿后 commit。
