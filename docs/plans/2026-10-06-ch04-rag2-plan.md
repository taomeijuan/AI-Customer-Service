# Ch04 实施计划：混合检索 + 重排 + 生成质控 + 评估体系

> **For implementer:** Use TDD throughout. Write failing test first. Watch it fail. Then implement.

**Goal:** query_faq 检索升级为 dense+BM25 混合（RRF 融合）+ bge-reranker 精排，生成带引用可拒答可自评，四策略评估对比出报告。

**Architecture:** milvus_store 升级 v2 集合（BM25 函数 + sparse + hybrid_search）→ retriever（改写→融合→过滤→精排）→ answerer（首尾组装+自评拒答）→ orchestrator 接线（citations/低置信度池）→ evals（metrics/faithfulness/runner 四策略）→ 前端 Vibe。

**Tech Stack:** Milvus 2.5 原生 BM25（chinese analyzer）+ hybrid_search RRFRanker · SiliconFlow /v1/rerank（bge-reranker-v2-m3）· build_structured_model（function_calling）· MySQL 台账

**Context7 核对结论（2026-10-06）：**
1. BM25 全文索引：`schema.add_field("text", DataType.VARCHAR, max_length=9000, enable_analyzer=True)`（analyzer_params={"type":"chinese"}）+ `schema.add_field("sparse", DataType.SPARSE_FLOAT_VECTOR)` + `Function(name=..., input_field_names=["text"], output_field_names="sparse", function_type=FunctionType.BM25)` + `schema.add_function(...)`；索引 `SPARSE_INVERTED_INDEX` + `metric_type="BM25"`（params bm25_k1/bm25_b）
2. hybrid_search：`AnnSearchRequest(data, anns_field, param={"metric_type": ...}, limit, filter=...)`；dense 路 data=[向量] metric COSINE，BM25 路 **data=[原始查询文本]** metric BM25（函数在检索期自动文本→sparse）；ranker 用 `RRFRanker(k=60)`；MilvusClient.hybrid_search(collection, reqs, ranker, limit, output_fields)
3. SiliconFlow rerank：`POST /v1/rerank` Bearer 认证，body `{model:"BAAI/bge-reranker-v2-m3", query, documents:[str], top_n, return_documents}`，响应 `{results:[{index, relevance_score, document}]}`（index 指回 documents 下标）
4. pymilvus 3.0.2 本地内省兜底：Function/FunctionType/AnnSearchRequest/RRFRanker 的导出与签名以安装版为准（ch03 教训：Context7 记 2.x 形态）

**约定：** 单测 Fake 注入；评估报告真链路；每任务绿后 commit。
