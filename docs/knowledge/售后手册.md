# 售后手册

## 特殊商品退换规则

生鲜食品、贴身衣物、定制商品等特殊商品，签收后不支持7天无理由退货，最终解释权归平台所有。若存在质量问题，可在30天内凭凭证申请售后。

## 退换货情形对照表

下表列出常见售后情形的时限与费用承担：

| 情形 | 时限 | 运费承担 | 备注 |
| --- | --- | --- | --- |
| 质量问题退货 | 30天 | 平台承担 | 需提供照片凭证 |
| 七天无理由退货 | 7天 | 买家承担 | 商品未拆封 |
| 尺码不合适换货 | 15天 | 买家承担 | 仅限首次换货 |
| 破损补发 | 48小时 | 平台承担 | 拆箱视频为凭证 |
| 发错货 | 48小时 | 平台承担 | 主动报备免追责 |

## 退款到账时效

各支付渠道退款到账时间不同：支付宝与微信支付1-3个工作日，银行卡3-7个工作日，礼品卡即时到账。超时未到账请联系人工客服核查。
