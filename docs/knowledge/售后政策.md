# 售后政策

## 退款

### 退款时限
自签收之日起7天内可申请无理由退货退款。退款审核通过后1-3个工作日原路退回，具体到账时间以支付平台为准。超过30天的质量问题退款需提供质检凭证。

### 退款方式
退款默认原路退回至付款账户。优惠券抵扣部分按实际支付金额退还。

## 运费说明

### 邮费与包邮规则
普通订单满99元包邮，不满99元收取8元邮费。偏远地区（新疆、西藏、内蒙古等）每单加收10元运费。会员等级达到金牌及以上全场免邮。

### 退货运费承担
质量问题退换货运费由平台全额承担；非质量问题（不喜欢、尺码不合适）7天内退货运费由买家自行承担，8元每单。

## 换货

### 换货流程
在「我的订单」选择对应商品申请换货，寄回旧商品后仓库验收合格即发出新商品，全程运费由平台承担。
