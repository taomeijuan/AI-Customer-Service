# 商品FAQ

## 空气炸锅可以用洗碗机洗吗
空气炸锅的内胆和炸篮可以放入洗碗机清洗，主机身含有电路元件，绝对不可以水洗或浸水，请用湿布擦拭。

## 空气炸锅 AF-102 怎么设置预约定时
长按控制面板的「预约」键进入预约定时模式，旋转旋钮选择预约时长（最长12小时），按启动键确认。AF-102 型号支持 8 段预设菜单。

## 无线蓝牙耳机可以同时连两台设备吗
不支持同时连接两台设备。耳机采用单点连接方案，切换设备需要先断开当前连接再重新配对。

## 耳机 EB-55 可以连电脑吗
EB-55 型号随附 USB 接收器，插入电脑 USB 口即可即插即用连接；也可以通过蓝牙配对连接带蓝牙模块的电脑。

## 保温杯可以装碳酸饮料吗
不建议。碳酸饮料产生的气压可能导致杯盖弹开或密封圈老化漏气，保温杯适合装水、茶饮和咖啡。
