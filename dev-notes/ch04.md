## 阶段 0：需求与环境（2026-10-06）

**用户关键原话**：
- 「我要用 Superpowers 模式把客服系统的检索质量做上一个台阶：混合检索加重排，再配一套评估体系。」
- 要点：①混合检索——关键词路落在 Milvus 2.5 原生 BM25（text 字段挂 BM25 函数、chinese analyzer），dense+BM25 各 Top-50，hybrid_search 配 RRF 融合；②重排 bge-reranker-v2-m3 精排 Top-10，组装 prompt 时最相关放首尾；③元数据过滤（按品类等先滤再检）；④Query 理解：口语改写归一 + 同义词只在检索侧扩展；⑤生成质控：引用编号可映射章节路径跳原文、检索不到/置信度低显式拒答、模型自评不够则拒答并入 low_confidence_questions 池、System Prompt 列负面知识禁承诺；⑥评估体系：难度梯度标注评估集，Recall@K/MRR/Faithfulness，四策略对比（纯向量/纯 BM25/混合/混合+Rerank）按 query 类型分桶出报告；⑦前端：引用编号可点显示来源原文+章节路径、回答左下角 👍/👎 一次性锁定反馈（纯前端采集，为 ch09 数据飞轮留入口）
- 技术栈定死：Milvus 原生 BM25 + hybrid_search RRF；bge-reranker-v2-m3
- 不做：指代消解、多轮改写
- 验收：①四策略对比报告出数字 ②带具体型号的问题 BM25 路能命中 ③引用编号定位回原文可点开 ④知识库没有的内容明确拒答且入池
- 两表 DDL（low_confidence_questions、faith_cases）用户直接提供为规范；faith_cases 带跨轮台账设计（uk_eval_id 一题一行、seen_count、复发退回未解决、citations 快照 Top-K 全集）

**关键产出**：任务跟踪（#23-26）

**用户拒绝或纠偏**：无。

**翻车与返工**：无。
