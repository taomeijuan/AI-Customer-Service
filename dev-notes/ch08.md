## 阶段 16：全量终审与全链路联调（2026-10-15）

**用户关键原话**：「定位到已经完成的部分，继续完成没有执行完的部分」。

**评审结论**（子代理终审 `origin/main..HEAD`，排除前端 Vibe 文件）：M1–M5 + m1–m3。处置：

- **M1（`app/tools/wrappers.py`）**：`StructuredTool._parse_input` 原先在进入 `_run` 前用 Pydantic `model_validate` 拦截了「缺必填字段 / 类型不对」（不进 `engine.execute`、不落 `校验拦下` 审计），且默认 `extra="ignore"` 静默剥掉了多余字段（导致 `additionalProperties: false` 在外壳层失效）。子类化 `_EngineTool` 重写 `_parse_input` 原样透传 `dict` 入参，交由 `validate_args` + `engine.execute` 统一校验并记审计 ✓
- **M2（`app/workflow/text.py`）**：`tool_answer_to_text` 原先只为 `query_warranty`/`query_return` 解包了 `data["data"]`，导致生产注册表路径下 `query_order`/`query_logistics`/`query_product` 引用卡片内容全空。改为入口统一解包 `{"ok": true, "data": ...}` 与 `{"ok": false, "error": ...}`，并补 `create_ticket` 引用模板 ✓
- **M3（`app/workflow/agent_node.py`）**：`_ToolFrameHandler` 从 `kwargs["inputs"]` 取工具入参；`on_tool_end` 解析引擎返回的 `"ok": false` 以准确发 `ok=False`；`on_tool_error` 忽略 `GraphInterrupt` 伪失败帧；MCP 适配器工具在 `_EngineTool` 内部嵌套 `ainvoke` 时按栈深去重不发双倍帧 ✓
- **M4 & m3（`app/workflow/agent_node.py`、`app/api/chat.py`）**：恢复唤醒后立即 `paused_agents.pop(cid, None)`（防异常/断连残留劫持后续新消息），跳过恢复轮重复的 `log_model_ctx`；`chat.py` 放弃挂起中断静默取消的 `finally` 块兜底清理 `paused_agents` ✓
- **M5（`app/workflow/graph.py`、`app/workflow/agent_node.py`）**：主图路由新增 `TICKET_HINT_RE`、`AFTERSALES_TOOL_RE` 与 `_is_direct_agent_turn`（含工单追问轮识别），避免建工单与保修/退货进度查询被 `refund_prep` 订单选择器或知识库检索拦截；提示词补齐 `query_warranty` 与 `query_return` 指引 ✓
- **m1 & m2（`app/tools/engine.py`、`app/tools/validate.py`）**：`execute` 支持 `spec=None` 记 `失败` 审计并返回 `工具未注册：…`；`validate.py` 补 `maxLength` 中文提示「长度超限」 ✓
